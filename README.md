# 🎬 Универсальный загрузчик видео (MediaLoader)

Одностраничный веб-сервис для скачивания **любых видео по любым ссылкам** в максимальном качестве (1080p / 4K / 8K) или только аудио (MP3).

---

## ⚡ Быстрый запуск

Просто дважды кликните по файлу:
```text
run.bat
```
Либо в терминале выполните:
```bash
uv run app.py
```

`uv` сам мгновенно подтянет и закеширует все необходимые библиотеки, запустит сервер и откроет сайт в вашем браузере по адресу `http://127.0.0.1:8000`.

---

## 💎 Особенности
* **Одностраничный интерфейс:** стильный светлый дизайн на Tailwind CSS и Plus Jakarta Sans.
* **Поддержка 1800+ платформ:** YouTube, VK, RuTube, Mail.ru, TikTok, Telegram, Instagram, Twitter/X, прямые ссылки `.mp4`, `.webm`, `.m3u8` и любые сайты с тегом `<video>`.
* **Встроенный FFmpeg:** высокое разрешение (1080p, 4K) объединяется с аудиопотоком автоматически.
* **Интерактивность:** предпросмотр ролика (обложка, название, автор, длительность), выбор качества, живой прогресс-бар (проценты, скорость, остаток времени) и список скачанных видео прямо на странице.
* **Сохранение:** видео попадают в папку [`downloads/`](downloads/) и доступны для сохранения прямо через браузер.
